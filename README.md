# 스마트기기 통합관리시스템(MDM) 연수용 시뮬레이터 — 디지털 튜터 수업용

서울특별시교육청 스마트기기 통합관리시스템 「Argos Edu Manager」(mdm.sen.go.kr)의 화면 구성과 공식 사용자 매뉴얼(v4.1)을 바탕으로 만든 실습용 재현본입니다.

- 바로 열기: https://songsamscience.github.io/mdm-simulator/
- 실제 단말·계정·정책에는 어떤 영향도 주지 않으며, 데이터는 전부 가상입니다.
- 실습 내용은 쓰는 브라우저에만 저장됩니다. 처음 상태로 되돌리려면 오른쪽 아래 「실습 미션」 → [처음 상태로]를 누르세요.

## 출처

- **원 제작: 해누리중 조승재 선생님** — 서울특별시교육청 디벗 전문가(테크니션) 직무연수 「윈도우 ADMIN · MDM UI 안내」 실습용 재현본
  (https://scienceisjo.github.io/growing-teachers/dibut/argos.html)
- **일부 변경: 아주중 송세호 선생님** — 디지털 튜터 수업을 위해 일부 내용을 변경했습니다.
  - 실제 화면과 같은 배치(아이콘 메뉴·남색 상단 바·홈 2열)
  - 학교명·계정·대여자 등 예시 정보의 가상화
  - 실습 미션 16개 화면 안내 보완(멈추던 단계 수정), 처리 이력 예시를 단말 현황과 일치시킴
  - 첫 화면을 실제 로그인 화면 배치로 바꾸고, 안내·도움말 문구를 실제 화면과 맞게 바로잡음(2026-10-31)
