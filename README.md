# 스마트기기 통합관리시스템(MDM) 연수용 시뮬레이터 — 디지털 튜터 수업용

서울특별시교육청 스마트기기 통합관리시스템 「Argos Edu Manager」(mdm.sen.go.kr)의 화면 구성과 공식 사용자 매뉴얼(v4.1), Android(Argos · AMA) · iPad(ASM) 사용자 매뉴얼을 바탕으로 만든 실습용 재현본입니다.

- 바로 열기: https://songsamscience.github.io/mdm-simulator/
- 실제 단말·계정·정책에는 어떤 영향도 주지 않으며, 데이터는 전부 가상입니다.
- 실습 내용은 쓰는 브라우저에만 저장됩니다. 처음 상태로 되돌리려면 오른쪽 아래 「실습 미션」 → [처음 상태로]를 누르세요.

## 실습 기종

로그인한 뒤 「실습할 기종을 고르세요」에서 **Windows 디벗 · Android 태블릿(AMA 포함) · iPad(ASM)** 가운데 하나를 고릅니다. 학교마다 쓰는 기종이 달라, 고른 기종의 단말 · 통합 설정 · 실습 미션으로 연수합니다. 기종마다 실습 기록이 따로 저장되며, 위쪽 [기종] 단추로 바꿀 수 있습니다.

| 기종 | 실습 미션 | 통합 설정 위자드 |
|---|---|---|
| Windows | 16개 | 6단계 |
| Android (Argos · AMA) | 13개 | Android 8단계 · AMA 5단계 |
| iPad (ASM) | 10개 | 9단계 |
